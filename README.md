Responsive Web Layout Exercises
This repository contains a collection of responsive web design exercises created to practice building complete landing pages from visual references.

Each exercise focuses on reproducing a different website style while applying responsive design principles for desktop, tablet, and mobile screens.

Included Exercises
Industry — A construction-company landing page with a hero section, services, portfolio, statistics, testimonials, blog cards, and call-to-action areas.

Paint — A portfolio-style website with responsive navigation, feature sections, cards, image galleries, and a blog layout.

Pretty — A beauty-salon landing page featuring a full-screen hero, services, team section, promotional content, gallery, partners, and appointment form.

Technologies Used
HTML5 for page structure and semantic content.

CSS3 for custom styling, layouts, responsive design, Flexbox, CSS Grid, media queries, and visual effects.

Bootstrap 5 for the responsive grid system, utility classes, navigation, cards, and interface components.

Bootstrap Icons in the Industry exercise.

Responsive images in WebP format.

Learning Goals
These exercises were created to practice:

Creating responsive interfaces for different screen sizes.

Using Bootstrap alongside custom CSS.

Building sections such as headers, navigation bars, cards, galleries, testimonials, forms, and footers.

Organizing page content with Flexbox, Grid, and Bootstrap's layout system.

Matching the visual hierarchy, spacing, colors, and structure of design references.

Each folder is an independent static website exercise and includes its own HTML, CSS, image assets, and screenshots for desktop, tablet, and mobile views.
